# Sync-Skripte

Kopie der Skripte aus dem PriesSync-Ordner auf Herberts Rechner. Sie laufen dort
täglich um 08:55 über `sync_start.bat` (Preis-Sync, Aktionspreise, Quiz-Textindex,
Übersetzungen). Die Fassung hier ist die Vorlage und wird bei jeder Änderung von
den Tests in `tests/sync` geprüft. Datendateien (Shop-Beschreibungen,
Zwischenspeicher, Logs) bleiben nur auf dem Rechner.
